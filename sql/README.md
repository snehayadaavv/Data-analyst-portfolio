## SQL Examples

This folder collects **SQL queries** that demonstrate how I work with relational data.

### Topics

- customer **cohorts and retention**  
- **funnel** analysis (acquisition, activation, subscription)  
- **segmentation** by behavior, location, or value  
- basic **data quality checks** and diagnostics.

### Project SQL files (`projects/` subfolder)

- `projects/customer_churn.sql` – monthly churn and retention base table  
- `projects/sales_performance.sql` – revenue, margin, and target variance by month/region  
- `projects/marketing_funnel.sql` – funnel conversion by channel and A/B test variant

Each `.sql` file includes:

- a short problem statement in comments  
- the core query or query set  
- notes about performance or trade‑offs where relevant.
