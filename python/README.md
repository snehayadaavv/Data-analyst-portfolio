## Python Analytics

This folder contains **Python notebooks and scripts** for data cleaning, exploration, visualization, and basic modeling.

### Common patterns

- loading and validating raw data  
- cleaning, joining, and reshaping with `pandas`  
- exploratory data analysis (EDA) with `matplotlib` / `seaborn`  
- simple predictive models (e.g., churn propensity using logistic regression).

### Project Python files (`projects/` subfolder)

- `projects/customer_churn.py` - risk scoring and churn profiling workflow  
- `projects/sales_performance.py` - variance-to-target diagnostics by segment  
- `projects/marketing_funnel_ab_test.py` - conversion lift summary for A/B test

Each notebook/script focuses on a clear question and ends with a short **written takeaway**.
