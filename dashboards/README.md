## Dashboards

This folder contains **Power BI** and **Excel** dashboards that summarize key metrics for different stakeholders.

- `executive-overview/` – high‑level business health (revenue, customers, churn, NPS)  
- `operations-support/` – support volume, SLAs, and team efficiency  
- `marketing-performance/` – campaign metrics, CAC, LTV, and ROI

Each dashboard subfolder should include:

- the dashboard file (`.pbix` or `.xlsx`)  
- a **README** describing the audience, main questions, and navigation tips  
- one or more **screenshots** for quick viewing on GitHub.

Current structure:

- `executive-overview/README.md` + `executive-overview/screenshots/`
- `operations-support/README.md` + `operations-support/screenshots/`
- `marketing-performance/README.md` + `marketing-performance/screenshots/`
