## Projects Overview

This folder holds **end‑to‑end case studies** that mirror real business problems.

- `customer-churn/` – telecom‑style churn analysis and retention strategy  
- `sales-performance/` – revenue and margin performance review  
- `marketing-funnel/` – funnel analysis and A/B test evaluation

Each project contains:

- a short **problem brief**  
- cleaned or sample **data** (or a data dictionary)  
- **SQL / Python** used for analysis  
- a concise **insight summary** and recommended actions.
